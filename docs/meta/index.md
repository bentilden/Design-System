# Metadata

Metadata makes the design system accountable. Each page should say what it is, where it came from, who it serves, and how trustworthy it is.

The metadata model exists for four reasons:

1. Separate observed behavior from approved guidance.
2. Preserve links between documentation and implementation.
3. Make review and audit work visible.
4. Enable future generated indexes, such as pages needing accessibility review or patterns mapped to a Twig template.

Use the schema for every new documentation page.
